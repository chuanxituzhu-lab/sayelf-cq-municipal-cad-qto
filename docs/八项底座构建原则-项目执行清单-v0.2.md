# 八项底座构建原则：CAD 造价算量执行清单

版本：v0.2
适用范围：本仓库的 DXF 图纸检查、挡护结构工程量计算、结果复核和 AI 插件适配

本清单把八项原则落到 `sayelf-cq-municipal-cad-qto` 的真实核心：用本地 CAD 图纸和人工确认断面参数生成可追溯的造价算量草稿。岗位成果、项目管理、即时通讯和通用 ERP 不属于本仓库。

## 执行门禁

新能力必须经过：

```text
搜索现有能力 → 比较缺口 → 分类决策 → 构建决策记录
→ 最小实现 → 聚焦验证 → 数据泄露检查 → 版本化与回滚准备
```

没有可量化差异、验证证据或清晰数据边界，不进入正式实现和外部发布。

## 八项原则映射

| 编号 | 原则 | CAD 造价算量落地 | 检查证据 |
|---|---|---|---|
| 01 | Negative Entropy | 只保留 DXF 检查、标准化、挡护结构规则、作业证据和人工复核 | [项目核心内容](./项目核心内容梳理-v0.1.md) |
| 02 | Modular / Pluggable | `dxf`、`canonical`、`recognition`、`retaining`、`job` 分层；MCP 仅作适配层 | [核心代码](../cad_qto/) 与插件目录 |
| 03 | Local-first | 解析、几何统计、规则计算、哈希和结果保存均在本地完成 | [README](../README.md) 与回归测试 |
| 04 | Dynamic by State | 作业按 `DRAFT → PARSED → NORMALIZED → CALCULATED → REVIEW_REQUIRED → APPROVED` 推进 | [字段与测试基线](./重庆市政图纸算量-字段与测试基线-v0.1.md) |
| 05 | Intelligent Automation | `Observation / Inference / Hypothesis / Fact` 分层；图纸候选不直接成为事实 | 作业中的 `status`、`review_status`、`evidence_refs` |
| 06 | Evidence-driven Evolution | 规则包版本化；合成样例、回归测试、脱敏双算后再升级 | [CAD 算量 BDR](./CAD算量范围收敛-BDR-v0.2.md) |
| 07 | WebUI as Human Interface | WebUI 只服务 `打开 → 输入 → 执行 → 结果 → 复核`，显示公式、哈希、告警和状态 | [WebUI 决策记录](./新WebUI-构建决策记录-v0.1.md) |
| 08 | Local Data & Sensitive Data Sovereignty | 原图、标准化图、算量作业和审核记录留在项目私有目录；接口拒绝越界路径和公共 URL | `server.py` 路径校验与数据目录检查 |

## 数据与发布结论

- 真实施工图、合同、照片、工程量底稿、造价文件、人员信息和凭据：`Sensitive/Restricted`，只留在本地信任边界。
- 合成 DXF、脱敏代码、工具契约和公开标准链接：逐项检查后才可标记为 `Public`。
- GitHub、外部模型、第三方 API 和遥测默认不接收真实项目数据；远程 AI 宿主只能调用经授权的私有适配器。

## 已有证据与缺口

已完成：

- 工作区、GitHub 和开源生态检索，并将本次收敛分类为 `Improve`；
- ASCII DXF 解析、标准化、挡护结构确定性计算、作业证据和审核状态；
- 本地 WebUI、API、MCP 工具和合成 DXF 回归测试；
- 主代码、主页面和发布文件的非 CAD 功能清理。

仍需真实项目验证：

- 真实重庆项目脱敏 DXF 与人工底稿双算；
- DWG 本地转换器的许可证、版本和失败样本；
- 重庆清单/定额映射和计价口径的正式依据；
- 审核通过后的人工导出或造价系统接口验收。

在这些证据完成前，系统不得宣称生产级全自动识别、套价或自动入账。
