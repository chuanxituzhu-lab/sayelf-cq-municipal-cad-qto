# CAD 造价算量 WebUI 构建决策记录

版本：v0.1
范围：`sayelf-cq-municipal-cad-qto` 的本地 CAD 算量工作台

WebUI 只服务造价算量，普通路径为：

```text
打开 → 输入 DXF → 检查/标准化 → 输入人工确认断面 → 执行 → 查看结果与证据 → 复核
```

首屏只展示：输入格式、支持实体、道路/管网/挡护规则包、最近作业、单/多文件录入、图纸检查、专业算量和审核门。不展示岗位任务、项目成员、周报、钉钉或其他项目管理功能。

实现采用 Python 标准库服务和原生 HTML/CSS/JavaScript，复用现有 `/api/cad/*` 能力，不复制工程量公式，不新增外部依赖。结果区必须显示 `Hypothesis / Inference / Fact` 边界、源图哈希、标准化图哈希、规则版本和告警。

验收证据：浏览器标题为“重庆市政 CAD 工程量计算（造价算量）”；合成 DXF 可生成 13 条明细；默认状态为 `REVIEW_REQUIRED`；原生测试和 API 冒烟通过。
