# sayelf-cq-municipal-cad-qto：项目核心内容

版本：v0.1
项目定位：重庆市政施工图 CAD 工程量计算与造价核对辅助工具

## 一句话定义

在本地把项目内 DXF 图纸转换为可追溯的工程量计算草稿，重点服务造价算量和人工核对；不把图层猜测、公式结果或未认证审核直接当成正式结算事实。

## 核心工作流

```text
打开算量工作台
  → 输入项目内 DXF 相对路径
  → 检查图层、实体、文字和未支持实体
  → 生成标准化 DXF（不覆盖原图）
  → 人工确认挡护结构断面参数
  → 执行确定性工程量计算
  → 查看数量、公式、哈希、告警和作业
  → 人工复核并决定是否进入正式造价流程
```

## 当前核心模块

| 模块 | 作用 | 结果口径 |
|---|---|---|
| `cad_qto.dxf` | 解析 ASCII DXF 的 `LINE`、`LWPOLYLINE`、`TEXT`、`MTEXT` | `Observation` |
| `cad_qto.canonical` | 生成标准化 DXF 和 SHA-256 | `Observation` |
| `cad_qto.recognition` | 根据图层和文字给出专业候选 | `Hypothesis` |
| `cad_qto.retaining` | 计算挡墙、基础、开挖、回填、泄水孔、反滤层、锚杆、抗滑桩、喷射混凝土、钢筋网 | `Inference` |
| `cad_qto.job` | 组装输入快照、公式、结果、告警和证据 | `Inference` |
| `cad_qto.review` | 记录五项人工检查和审核状态 | `Fact` 只在身份核验后成立 |
| `municipal-cad-qto` | 为 Codex、Claude Code、WorkBuddy、千问/豆包私有部署提供 MCP 入口 | 统一工具契约 |

## 当前算量范围

- 输入：项目根目录内 ASCII DXF 相对路径；
- 统一输出：标准化 ASCII DXF 副本；
- 挡护结构：墙身、基础、基坑开挖、墙背回填、泄水孔、反滤层、锚杆/锚索、抗滑桩、喷射混凝土、钢筋网；
- 规则包：`cq-municipal-retaining-v0.1`；
- 结果：数量、单位、公式、输入快照、源图/标准化图哈希、告警和审核状态；
- 造价边界：当前只做几何工程量，不自动套重庆定额、清单、综合单价或结算口径。

## 可信边界

- 图层和文字只能产生 `Hypothesis`；
- 公式计算是 `Inference`，必须以人工确认断面为输入；
- 识别到未支持实体、缺少关键尺寸、单位异常或数量告警时必须人工复核；
- 未经本地已认证身份审核的结果不能成为 `Fact`；
- 真实图纸、合同、计价文件和项目数据只留在本地私有目录。

## 不属于本仓库核心的内容

岗位成果管理、现场照片管理、生产/技术岗位闭环、项目成员、钉钉登录、周报/月报、通用 ERP、自动套定额/单价、自动审批和自动入账均不属于本仓库。
