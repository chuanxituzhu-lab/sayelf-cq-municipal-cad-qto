# sayelf-cq-municipal-cad-qto：项目核心内容

版本：v0.3（范围修订）
项目定位：重庆市政施工图 CAD 工程量计算与造价核对辅助工具

## 一句话定义

在本地把项目内 DXF 图纸和人工确认的道路、管网、挡护参数转换为可追溯的工程量计算草稿，服务造价算量和人工核对；不把图层猜测、公式结果或未认证审核直接当成正式结算事实。

## 两个仓库的硬隔断

`sayelf-cq-municipal-cad-qto` 是 CAD 工程量计算仓库；`sayelf-municipal-cost-loop` 是另一个独立仓库。两者不互相导入、不互相调用、不共享数据库、项目目录、身份、工作记录、报告或 API。本仓库只处理 CAD 输入、几何规则、算量结果和复核证据。

## 核心工作流

```text
打开算量工作台
  → 单选 / 多选 DXF 文件录入到本仓库私有目录
  → 逐张检查图层、实体、文字、单位和未支持实体
  → 生成标准化 DXF（不覆盖原图）
  → 人工确认道路 / 管网 / 挡护专业参数
  → 执行确定性工程量计算
  → 查看数量、公式、输入快照、哈希、告警和作业
  → 人工复核并决定是否进入正式造价流程
```

## 当前核心模块

| 模块 | 作用 | 结果口径 |
|---|---|---|
| `cad_qto.dxf` | 解析 ASCII DXF 的 `LINE`、`LWPOLYLINE`、`TEXT`、`MTEXT` | `Observation` |
| `cad_qto.canonical` | 生成标准化 DXF 和 SHA-256 | `Observation` |
| `cad_qto.recognition` | 根据图层和文字给出道路、管网、挡护候选 | `Hypothesis` |
| `cad_qto.road` | 计算路面层、路基挖填、路缘石、侧平石/人行道 | `Inference` |
| `cad_qto.network` | 计算管道、沟槽开挖、垫层、回填、检查井、雨水口、道路恢复 | `Inference` |
| `cad_qto.retaining` | 计算墙身、基础、开挖、回填、泄水孔、反滤层、锚杆、抗滑桩、喷射混凝土、钢筋网 | `Inference` |
| `cad_qto.job` | 组装多专业输入快照、规则、结果、告警和证据 | `Inference` |
| `cad_qto.review` | 记录五项人工检查和审核状态 | `Fact` 只在身份核验后成立 |
| `municipal-cad-qto` | 为 Codex、Claude Code、WorkBuddy、千问/豆包私有部署提供 MCP 入口 | 统一工具契约 |

## 当前算量范围

### 道路工程

规则包：`cq-municipal-road-v0.1`。

- 路面面层、基层、底基层；
- 路基挖方、填方；
- 路缘石、侧平石/人行道；
- 以长度、宽度、厚度、断面面积等人工确认参数计算。

### 管网工程

规则包：`cq-municipal-network-v0.1`。

- 管道长度与管道体积；
- 沟槽开挖、砂石垫层、回填；
- 检查井、雨水口；
- 道路恢复面积；
- 以管径、沟槽宽深、构筑物数量等人工确认参数计算。

### 挡护工程

规则包：`cq-municipal-retaining-v0.1`。

- 墙身、基础、基坑开挖、墙背回填；
- 泄水孔、反滤层；
- 锚杆/锚索、抗滑桩；
- 喷射混凝土、钢筋网/挂网。

三类结果均保留分项编码、单位、数量、公式、输入快照、规则包版本、源图/标准化图哈希、告警和审核状态。道路、管网、挡护可以在一个作业中综合计算，但多张图纸始终分别留痕，不混淆源文件。

## 可信边界

- DXF 实体、图层、文字和哈希是 `Observation`；
- 图层/文字推导的专业候选是 `Hypothesis`；
- 依据人工确认参数和版本化公式得到的数量是 `Inference`；
- 通过原图、设计依据、专业参数、单位/规则、工程部位五项检查并完成本地身份核验后，才允许成为 `Fact`；
- 缺少关键尺寸、单位异常、未支持实体或数量告警时，系统不补猜，必须人工复核；
- 当前只做几何工程量，不自动套重庆定额、清单、综合单价、结算口径，不自动审批或入账。

## 数据边界

- `Public`：代码、合成 DXF、脱敏文档、工具契约；审核后可发布；
- `Sensitive/Restricted`：真实施工图、合同、计价文件、现场资料和审核信息，只留在本地；
- 上传的 DXF 只写入本仓库 `data/cad_inputs/`，算量作业写入本仓库 `data/cad_jobs/`；不进入 GitHub，不传给外部模型，不复制到 cost-loop 仓库。

## 不属于本仓库核心的内容

岗位成果管理、现场照片管理、生产/技术岗位闭环、项目成员、钉钉登录、周报/月报、通用 ERP、自动套定额/单价、自动审批、自动入账、OCR/视觉识别和通用 DWG/PDF/BIM 解析器均不属于本仓库。
