# 市政工程岗位成果闭环演示项目：核心内容梳理

版本：v0.1
日期：2026-08-28
项目定位：重庆市政施工项目的本地优先、可审核、可追溯的 AI 辅助平台最小闭环

## 1. 一句话定义

把施工现场各岗位的成果、证据、审核和造价验证串成一条可追溯链；把 CAD 图纸识别与工程量计算作为其中一个受控工作面，AI 只负责辅助发现、编排和解释，最终事实由人工审核确认。

## 2. 当前最小闭环

```text
项目任务
  → 岗位成果提交
  → 证据留存
  → 生产/技术审核
  → 造价验证
  → 周报/月报与可核对结果
```

```text
项目内 DXF
  → 保守解析与标准化
  → 图层/实体候选识别（Hypothesis）
  → 人工确认挡护结构断面
  → 规则计算工程量（Inference）
  → 显示公式、哈希、告警和证据
  → 人工复核后才能成为 Fact
```

## 3. 核心模块与责任边界

| 模块 | 当前职责 | 输出 | 不负责 |
|---|---|---|---|
| `cad_qto.dxf` | 解析 ASCII DXF 的保守实体子集 | 实体、图层、文字、告警 | 判断设计意图 |
| `cad_qto.canonical` | 生成可复算的标准化 DXF 与哈希 | 标准化文件、SHA-256 | 上传或云端转换 |
| `cad_qto.recognition` | 根据图层和实体形成候选 | `Hypothesis` 候选 | 把候选当成事实 |
| `cad_qto.retaining` | 计算挡墙、基础、开挖、回填、泄水孔、反滤层、锚杆、抗滑桩、喷射混凝土、挂网 | 公式、数量、单位、告警 | 重庆定额/单价自动套用 |
| `cad_qto.job` | 组装作业输入、结果、证据和状态 | `REVIEW_REQUIRED` 作业 | 自动审批或自动入账 |
| `server.py` | 项目数据、岗位范围、成果、审核、CAD API、报告 | 本地 HTTP API | 替代规则核心 |
| `plugins/municipal-cad-qto` | Codex、Claude Code、WorkBuddy 的统一工具入口 | MCP/插件调用 | 复制业务逻辑 |
| `web/` | 人的工作入口 | 打开、输入、执行、结果 | 另建一套计算逻辑 |

## 4. 关键状态与事实分层

- 作业状态：`DRAFT → PARSED → NORMALIZED → CALCULATED → REVIEW_REQUIRED → APPROVED`。
- `Observation`：原始图层、实体、文字、文件哈希和人工录入尺寸。
- `Hypothesis`：由图层名或文字得到的构件候选和缺证提示。
- `Inference`：由已确认输入和明确公式推导出的工程量。
- `Fact`：生产、技术、造价审核完成后可用于闭环的结果。

任何关键尺寸缺失、图层匹配不唯一、实体不支持、单位异常、哈希变化或结果告警，都必须停在人工复核。

## 5. WebUI 必须解决的真实问题

WebUI 不是展示大屏，而是岗位人员的工作面。首屏必须回答：项目是谁、我是什么岗位、当前要做什么、哪一步待审核、下一步怎么走。

普通路径固定为：

```text
打开项目 → 查看工作面 → 输入或提交 → 执行 → 查看结果与证据 → 人工审核
```

新界面的最小验收指标：

1. 首屏显示完整项目名称“市政工程岗位成果闭环演示项目”；
2. 从项目总览进入“岗位成果”或“CAD 算量”不超过一次操作；
3. CAD 结果同屏展示状态、规则版本、源图/标准化图哈希、告警、公式和审核入口；
4. 所有按钮仍调用现有 API，不在浏览器端复制工程量公式；
5. 本地演示可在无外网、无模型、无真实图纸条件下用合成 DXF 完成可重复验证。

## 6. 数据边界

- `Public`：代码、合成 DXF、脱敏文档、插件契约；经过 staged diff 检查后可发布。
- `Sensitive/Restricted`：真实图纸、合同、现场照片、项目账本、造价文件、人员身份、密钥和运行数据；只留在项目私有目录。
- `Unknown`：未完成分类的文件一律不进入 GitHub 或其他外部网络。

本项目默认本地优先，不上传真实图纸，不把识别候选直接提升为事实，不自动写入正式造价系统。

## 7. 当前明确不建设

- 通用 DWG/PDF/扫描图自动识别器；
- OCR 或视觉模型直接生成可入账工程量；
- 重庆正式定额、清单、综合单价的无依据自动匹配；
- 全专业 BIM/ERP/多项目平台；
- 通过 WebUI 重写一份与 `cad_qto` 不一致的计算逻辑。
