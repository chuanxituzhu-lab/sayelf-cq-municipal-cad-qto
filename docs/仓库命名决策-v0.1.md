# 仓库命名决策 v0.1

## 结论

- 核心中文名：Sayelf 市政造价闭环
- GitHub 仓库名：`sayelf-municipal-cost-loop`
- 当前仓库地址：<https://github.com/chuanxituzhu-lab/sayelf-municipal-cost-loop>
- 建议项目描述：以造价为核心、生产与技术为两翼、三证互证的单项目市政工程成果闭环系统。

## 命名理由

`sayelf` 作为统一前缀，便于和后续工具、插件、技能保持同一产品族；`municipal` 明确市政工程场景；`cost` 明确造价核心；`loop` 表达岗位成果、生产审核、技术审核和造价验证形成闭环。

## 使用边界

- 以上结论是公开仓库检索结果，不等同于仓库所有者账号下的最终创建许可；创建前还要检查目标账号或组织名下是否已有同名私有仓库。
- 当前代码中的插件包名 `municipal-cad-qto`、连接器 ID `municipal-project-loop` 暂不改名，它们是已完成安装和配置的兼容标识。
- 仓库创建后，插件包可继续放在 `plugins/municipal-cad-qto/`；仓库名和插件名不要求完全相同。
- 真实项目图纸、合同、照片、人员身份、造价文件、密钥和日志不进入公开仓库。
