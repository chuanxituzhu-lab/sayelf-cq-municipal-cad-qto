# 钉钉—千问正式接入步骤 v0.1

## 一、推荐链路

```text
钉钉工作台
    ↓
千问办公
    ↓
市政项目管理连接器
    ↓
私有项目闭环系统
```

钉钉负责身份和启动入口，千问负责智能交互，项目后台负责真正的岗位权限和工程数据。

## 二、管理员需要配置的内容

### 钉钉侧

- 创建企业内部应用或 H5 微应用；
- 获取企业 CorpId；
- 获取应用 AppKey/Client ID；
- 配置应用首页和 HTTPS 回调地址；
- 开通读取当前登录用户身份的权限；
- 将应用加入钉钉工作台。

### 千问侧

- 创建或选择企业组织；
- 绑定钉钉 SSO；
- 发布“市政项目管理”项目入口；
- 配置项目连接器地址；
- 预加载岗位能力和周/月报能力。

### 项目后台

- 设置唯一 `PROJECT_ID`；
- 导入项目成员名单；
- 设置岗位、工作类别和管理归口；
- 设置造价系统项目编号；
- 配置私有文件存储；
- 配置三证互证规则。

## 三、普通用户使用

```text
钉钉登录
→ 打开项目入口
→ 首次授权一次
→ 自动获取本人岗位
→ 直接提交成果或拍照上传
```

普通用户不填写项目编号、不选择岗位、不配置连接器、不输入接口密钥。

## 四、正式接入前的必要条件

- 企业钉钉管理员账号；
- 千问企业组织管理员账号；
- 一个可使用 HTTPS 的项目访问域名；
- 私有项目服务器或企业私有云；
- 造价系统的导入模板或接口说明；
- 试运行项目的岗位人员名单。

## 五、上线验收

1. 普通成员从钉钉进入后无需再次登录。
2. 后台能够按钉钉用户 ID 匹配正确岗位。
3. 离职或移出项目后立即不能访问项目数据。
4. 施工员/测量员可以手机拍照并提交成果。
5. 生产经理和技术负责人看到的审核范围不同。
6. 造价经理只能验证三证齐全的记录。
7. 千问不能越权读取其他项目或直接批准造价数据。
8. 造价验证失败时可以保留原始记录并人工处理。
