# 重庆市政图纸算量字段与测试基线

版本：v0.3（道路 / 管网 / 挡护）

## 1. 通用输入契约

```json
{
  "source_file": "项目目录内的 DXF 相对路径",
  "road_rule_pack_version": "cq-municipal-road-v0.1",
  "network_rule_pack_version": "cq-municipal-network-v0.1",
  "retaining_rule_pack_version": "cq-municipal-retaining-v0.1",
  "road_sections": [],
  "network_sections": [],
  "retaining_sections": []
}
```

至少提供一个非空专业数组。数组可以同时提供，系统在一个作业中合并结果，但每条明细仍保留 `discipline` 和对应规则版本。旧版 `sections` 等同于 `retaining_sections`，仅为兼容。

所有尺寸必须来自人工确认的图纸、断面表、设计说明或构筑物表。缺失时系统停止该分项计算或给出告警，不补猜。

## 2. 道路参数

每个 `road_sections` 对象至少包含：

```json
{
  "section_id": "RD-001",
  "station_start": "K0+000",
  "station_end": "K0+030",
  "length_m": 30,
  "carriageway_width_m": 7,
  "surface_thickness_m": 0.18
}
```

可选字段：`base_thickness_m`、`subbase_thickness_m`、`cut_area_m2_per_m`、`fill_area_m2_per_m`、`curb_length_m`、`curb_cross_section_m2`、`sidewalk_area_m2`。输出路面面积、面层/基层/底基层体积、挖方、填方、路缘石和人行道面积。

## 3. 管网参数

每个 `network_sections` 对象至少包含：

```json
{
  "segment_id": "PS-001",
  "station_start": "K0+000",
  "station_end": "K0+030",
  "length_m": 30,
  "pipe_outer_diameter_mm": 600,
  "trench_width_m": 1.2,
  "trench_depth_m": 1.8
}
```

可选字段：`bedding_thickness_m`、`backfill_top_m`、`manhole_count`、`manhole_volume_m3`、`inlet_count`、`inlet_volume_m3`、`road_restore_width_m`。输出管道体积、沟槽开挖、垫层、回填、检查井、雨水口和道路恢复面积。

## 4. 挡护参数

每个 `retaining_sections` 对象至少包含：

```json
{
  "section_id": "R-001",
  "length_m": 30,
  "wall_height_m": 4,
  "wall_base_width_m": 2.2,
  "wall_top_width_m": 0.6,
  "foundation_width_m": 2.4,
  "foundation_thickness_m": 0.5
}
```

可选字段：`excavation_area_m2_per_m`、`backfill_area_m2_per_m`、`drainage_hole_count` 或 `drainage_hole_spacing_m`、`filter_area_m2_per_m`、`anchor_count` 或 `anchor_spacing_m + anchor_rows`、`anchor_length_m`、`pile_count`、`pile_width_m`、`pile_depth_m`、`pile_length_m`、`shotcrete_area_m2_per_m`、`shotcrete_thickness_m`。

## 5. 输出契约

每条工程量包含：

```text
quantity_id / discipline / section_id / station
item_code / item / unit / quantity
formula / inputs / status=Inference
review_status=待人工审核
evidence_refs.source_file / source_sha256 / section_id
```

作业级别保留原始 DXF SHA-256、标准化 DXF SHA-256、解析器版本、各专业规则包版本、支持/未支持实体、图层清单、识别候选、工程量明细、总计、告警、输入快照和人工审核状态。

## 6. 当前规则公式摘要

| 专业 | 分项 | 公式 | 单位 |
|---|---|---|---|
| 道路 | 路面面积 | `长度 × 车行道宽度` | m² |
| 道路 | 面层/基层/底基层 | `长度 × 宽度 × 对应厚度` | m³ |
| 道路 | 挖方/填方 | `单位长度断面面积 × 长度` | m³ |
| 道路 | 路缘石 | `路缘长度 × 截面面积` | m³ |
| 管网 | 管道体积 | `π × (外径 / 2)² × 长度` | m³ |
| 管网 | 沟槽开挖 | `沟槽宽 × 沟槽深 × 长度` | m³ |
| 管网 | 垫层/回填 | `对应断面面积 × 长度` | m³ |
| 管网 | 道路恢复 | `恢复宽度 × 长度` | m² |
| 挡护 | 墙身 | `(墙底宽 + 墙顶宽) / 2 × 墙高 × 长度` | m³ |
| 挡护 | 基础 | `基础宽 × 基础厚 × 长度` | m³ |
| 挡护 | 开挖/回填 | `断面面积 × 长度` | m³ |
| 挡护 | 泄水孔 | 明确数量；或 `floor(长度 / 间距) + 1` | 个 |
| 挡护 | 锚杆 | 明确数量；或 `ceil(长度 / 间距) × 排数` | 根 |

这些是几何计算公式，不是重庆定额子目、综合单价或结算口径；正式清单/定额映射必须在人工确认并绑定正式依据后另行版本化。

## 7. 接口

- `GET /api/cad/status`：返回支持范围、专业、规则版本和审核门槛；
- `POST /api/cad/files`：单选/多选上传 DXF 到本地 `data/cad_inputs/`；
- `POST /api/cad/inspect` / `/api/cad/inspect-batch`：检查一张/多张 DXF；
- `POST /api/cad/calculate`：提交道路、管网、挡护任意组合并生成本地算量作业；
- `POST /api/cad/retaining`：旧版挡护入口；
- `GET /api/cad/jobs`、`GET /api/cad/jobs/{job_id}`：读取作业摘要/完整证据；
- `POST /api/cad/jobs/{job_id}/review`：写入人工复核决定。
