# 重庆市政图纸算量字段与测试基线

版本：v0.1

## 1. 输入契约

```json
{
  "source_file": "项目目录内的 DXF 相对路径",
  "rule_pack_version": "cq-municipal-retaining-v0.1",
  "sections": [
    {
      "section_id": "R-001",
      "station_start": "K0+000",
      "station_end": "K0+030",
      "length_m": 30,
      "wall_type": "重力式挡墙",
      "wall_material": "片石混凝土",
      "wall_height_m": 4,
      "wall_base_width_m": 2.2,
      "wall_top_width_m": 0.6,
      "foundation_width_m": 2.4,
      "foundation_thickness_m": 0.5
    }
  ]
}
```

可选字段覆盖：

- `excavation_area_m2_per_m`、`backfill_area_m2_per_m`：按挡墙长度折算的断面面积；
- `drainage_hole_count` 或 `drainage_hole_spacing_m`：泄水孔数量；
- `filter_area_m2_per_m`：反滤层面积；
- `anchor_count` 或 `anchor_spacing_m + anchor_rows`，以及 `anchor_length_m`：锚杆/锚索；
- `pile_count`、`pile_width_m`、`pile_depth_m`、`pile_length_m`：抗滑桩；
- `shotcrete_area_m2_per_m`、`shotcrete_thickness_m`：喷射混凝土和挂网。

所有尺寸必须来自人工确认的图纸、断面表或设计说明。缺失时系统停止该分项计算或给出告警，不补猜。

## 2. 输出契约

每条工程量包含：

```text
quantity_id / section_id / station / wall_type
item_code / item / unit / quantity
formula / inputs
status=Inference
review_status=待人工审核
evidence_refs.source_file / source_sha256 / section_id
```

作业级别保留：

- 原始 DXF SHA-256；
- 标准化 DXF SHA-256；
- 解析器版本、规则包版本；
- 支持实体、未支持实体和图层清单；
- 识别候选（`Hypothesis`）；
- 工程量明细和总计；
- 告警、输入快照和人工审核状态。

## 3. 当前规则公式

| 分项 | 公式 | 单位 |
|---|---|---|
| 墙身 | `(墙底宽 + 墙顶宽) / 2 × 墙高 × 长度` | m³ |
| 基础 | `基础宽 × 基础厚 × 长度` | m³ |
| 开挖/回填 | `断面面积 × 长度` | m³ |
| 泄水孔 | 明确数量；或 `floor(长度 / 间距) + 1` | 个 |
| 反滤层 | `单位长度面积 × 长度` | m² |
| 锚杆根数 | 明确数量；或 `ceil(长度 / 间距) × 排数` | 根 |
| 锚杆钻孔/注浆 | `根数 × 孔深` | m |
| 抗滑桩混凝土 | `根数 × 桩长 × 桩宽 × 桩深` | m³ |
| 喷射混凝土 | `单位长度面积 × 长度 × 厚度` | m³ |
| 钢筋网/挂网 | `单位长度面积 × 长度` | m² |

这些是几何计算公式，不是重庆定额子目、综合单价或结算口径；定额/清单映射必须在人工确认并绑定正式依据后另行版本化。

## 4. 接口

- `GET /api/cad/status`：返回支持范围、规则版本和审核门槛；
- `POST /api/cad/retaining`：提交项目内 DXF 与人工确认断面，生成本地算量作业；
- `GET /api/cad/jobs`：查看当前项目作业摘要；
- `GET /api/cad/jobs/{job_id}`：取得完整结果和证据引用。

正式模式下接口需要钉钉成员身份；后台不信任客户端传入的项目权限。源文件路径必须位于项目私有目录内，不接受公共 URL。
